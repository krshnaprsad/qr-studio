QR Studio

QR codes with your colours and your logo

v1.2.1

1. What should it open?

Anyone who scans this code can join the network. Only put it somewhere you are happy to share the Wi-Fi.

2. Style

Dot shape

Corner shape

Shapes marked with a small dot are decorative and harder for phones to read. The tool warns you, but always scan the result.

3. Logo (optional)

The logo sits in the middle and hides a little of the code. The repair level is set to the highest (H) so the code can still be read. Keep the logo small and always test the result with your phone.

Your code

SVG stays sharp at any size, use it for print. PNG is for screens and chat apps.

Why I built this

Sometimes a client needs a QR code. I make one from their website, and when it is scanned it opens that website, doing exactly what the QR code is for. It also works with my phone number: scan the code and it calls me, or opens WhatsApp. Anything a QR code is needed for, QR Studio does it.

Everything runs in your browser. What you type and the logo you add are not sent anywhere. Made by Zero3. Source on GitHub
